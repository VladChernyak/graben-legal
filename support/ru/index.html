Частые вопросы

Как сделать резервную копию данных?

Откройте Настройки → Данные → «Экспортировать личные данные». Файл содержит все ваши записи вместе с фото. Восстановить их можно кнопкой «Импортировать из файла» в том же разделе. Личные записи хранятся только на вашем телефоне, поэтому копия — единственный способ их вернуть.

Как присоединиться к отряду?

Откройте ссылку-приглашение или отсканируйте QR-код, который прислал участник отряда. Для этого нужно войти в приложение по адресу электронной почты.

Запись маршрута останавливается, когда гаснет экран

Разрешите приложению доступ к геолокации «Всегда»: Настройки iPhone → GRABEN → Геолокация. Без этого iOS останавливает запись вместе с экраном.

Работает ли приложение без интернета?

Ваши записи, маршруты и импортированные старые карты работают без связи. Спутниковая карта загружается, когда есть интернет.

Как удалить аккаунт?

Настройки → Аккаунт → «Удалить аккаунт навсегда». Подробнее о данных — в Политике конфиденциальности.
